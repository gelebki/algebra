# Algebrownia

Trening z Algebry Liniowej I (listy 1–3): odpowiedzi A/B/C/D z typowymi błędami, podobne przykłady do każdego podpunktu, wzory, poziomy, odznaki i ranking ze znajomymi.

- Postęp każdego gracza zapisuje się w jego przeglądarce.
- Ranking korzysta z Firebase (darmowy plan). Konfiguracja: plik `firebase-config.js`, reguły bazy: `firestore.rules`.
- Strona: Settings → Pages → *Deploy from a branch* → `main` / `(root)`.
